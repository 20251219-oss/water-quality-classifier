# AquaClass AI - 수질 오염 분류 시스템

분광 분석(Spectral Analysis)을 이용한 **머신러닝 기반 수질 오염 분류 웹 애플리케이션**입니다.

## 🌊 프로젝트 개요

물의 흡광도 스펙트럼 데이터를 입력하면 Random Forest 모델이 다음 4가지 수질 상태를 자동 분류합니다:

- **깨끗한 물** - 전 파장에서 균일하게 낮은 흡광도
- **유기물 오염** - 단파장(400nm)에서 높고 장파장으로 갈수록 급감
- **중금속 오염** - 500~550nm 중간 파장에서 피크
- **조류(녹조) 오염** - 650~700nm 장파장에서 피크 (엽록소 a)

## 🚀 기능

### 1. 직접 입력 분류
- 7개 파장(400nm, 450nm, 500nm, 550nm, 600nm, 650nm, 700nm)의 흡광도 값을 직접 입력
- 실시간 스펙트럼 그래프 미리보기
- 4가지 샘플 프리셋으로 빠른 테스트 가능

### 2. CSV 파일 업로드
- Vernier Spectral Analysis 앱에서 내보낸 CSV 파일 지원
- 드래그 앤 드롭 업로드
- 자동으로 7개 파장 데이터 추출 및 분류

### 3. 측정 기록
- 모든 분류 결과 히스토리 저장 (최대 20개)
- 분류 결과, 신뢰도, 시간, 출처(직접 입력/CSV) 기록
- 한 번에 기록 전체 삭제 가능

### 4. 모델 정보
- 모델 알고리즘 및 파라미터 상세 정보
- 오염 종류별 흡광 특성 설명
- 파장별 중요도(Feature Importance) 시각화
- 모델 정확도 및 학습 데이터 정보

## 📊 모델 성능

| 항목 | 내용 |
|------|------|
| **알고리즘** | Random Forest Classifier |
| **트리 개수** | 100개 앙상블 |
| **최대 깊이** | 10 |
| **테스트 정확도** | 95%+ (5-폴드 교차검증) |
| **학습 데이터** | 200개 샘플 |
| **입력 특성** | 7개 (파장별 흡광도) |
| **전처리** | StandardScaler 정규화 |

## 🛠️ 기술 스택

- **프론트엔드**: 순수 HTML5 + CSS3 + JavaScript (외부 라이브러리 없음)
- **UI/UX**: 다크 테마, 반응형 디자인
- **그래프**: Canvas API를 이용한 실시간 스펙트럼 시각화
- **분류**: 거리 기반 근사화 RF 분류기 (WebGL/WASM 없이 순수 JS)

## 📖 사용 방법

### 웹사이트 접속
```
https://20251219-oss.github.io/water-quality-classifier/
```

### 직접 입력으로 분류
1. "직접 입력 분류" 페이지에서 7개 파장의 흡광도 값 입력
2. 또는 "깨끗한 물", "유기물 오염" 등 프리셋 버튼으로 빠른 테스트
3. "오염 종류 분류하기" 버튼 클릭
4. 결과 패널에서 분류 결과와 신뢰도 확인

### CSV 파일 업로드로 분류
1. "CSV 파일 업로드" 페이지로 이동
2. 버니어 Spectral Analysis에서 내보낸 CSV 파일 선택 또는 드래그 앤 드롭
3. 자동으로 파일이 분석되고 결과 표시
